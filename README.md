# Maggie Mania

Maggie Mania is a campus-based food ordering web application developed using Node.js, Express, MongoDB Atlas, and EJS.  
The platform enables users to securely place orders, manage sessions, and track their profile details.

## Features
- User authentication with session-based login
- MongoDB Atlas integration using Mongoose
- Secure session storage with connect-mongo
- Input validation and sanitization
- Rate limiting for authentication and order routes
- Order placement and management
- Server-side rendering with EJS

## Tech Stack
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Express Session
- EJS
- Helmet & express-mongo-sanitize
